Personal-use desktop integration

Sync only what you choose.

Ubuntu Drive Sync is a personal-use OAuth application for connecting a local Ubuntu computer to a Google Drive account using the open-source Rclone command-line tool.

What it does

The owner authorizes access to their own Google Drive account through Google's OAuth consent screen. Rclone, running on the owner's Ubuntu computer, synchronizes selected local directories with selected Google Drive folders. Other Drive folders are not automatically downloaded.

How it works

  • Google OAuth is used to obtain consent to connect a Google Drive account.
  • Rclone transfers selected files directly between the owner's computer and Google Drive.
  • The local Rclone configuration controls which folders are synchronized and when.

Permission disclosure: The Google Drive OAuth permission technically allows broad access to Drive files; selecting a folder for synchronization limits the configured Rclone job, not the Google OAuth permission itself.

Private utility — not a hosted file service

This website is an information page only. It has no sign-in form, upload form, tracking scripts, or backend that receives Drive files or Google OAuth credentials. The application is not available as a public multi-user service.
